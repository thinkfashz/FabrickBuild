# FabrickBuild

FabrickBuild es una plataforma web de construcción inteligente preparada para desplegarse en Vercel.

## Estructura

- `site/`: portada web de FabrickBuild.
- `scripts/build.mjs`: genera la carpeta `dist/` para producción.
- `vercel.json`: configuración del despliegue.
- `LICENSE.md`: licencia MIT y aviso de copyright original conservados sin cambios.
- `NOTICE.md`: explicación de atribución y cambio de identidad.

## Desarrollo local

```bash
npm install
npm run dev
```

## Compilación

```bash
npm run build
```

## Producción

- Sitio: https://fabrickbuild.vercel.app
- Proyecto de Vercel: `fabrickbuild`

La identidad FabrickBuild, la portada y la configuración de despliegue son añadidos personalizados. Los derechos y la atribución del código de Payload CMS se mantienen conforme a su licencia MIT.
